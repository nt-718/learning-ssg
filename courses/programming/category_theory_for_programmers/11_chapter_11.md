# 第11章 宣言的プログラミング

## 1. 命令的定義

「どう作るか」を指定する。

## 2. 宣言的定義

「何を満たすものか」を指定する。

圏論の普遍性は極めて宣言的。

## 3. 積を思い出す

積を、

> ペア `(a,b)` の集合

と定義しなくても、

\[
X\to A
\]

と、

\[
X\to B
\]

を一意にまとめるものとして定義できる。

## 4. この方法の強さ

内部実装を知らなくても定義できる。

これはプログラミングの、

- interface
- protocol
- abstract data type

の思想に近い。
