# 第2章 型と関数

## 1. この章の狙い

圏論をプログラミングへ接続するため、

> 型を対象、関数を射として見る

という視点を導入する。

## 2. 型を集合として近似する

たとえば、

```haskell
Bool
```

には、

```text
True
False
```

という2値がある。

したがって有限集合として、

\[
|Bool|=2
\]

と考えられる。

## 3. Unit

```haskell
()
```

は値が1つしかない。

\[
|()|=1
\]

これは後の終対象につながる。

## 4. Void

値が存在しない型。

\[
|Void|=0
\]

これは始対象につながる。

## 5. 純粋関数

数学的関数では、

同じ入力に対して必ず同じ出力が得られる。

```haskell
square x = x * x
```

は純粋。

一方、

```cpp
int randomValue() {
    return rand();
}
```

は外部状態に依存する。

## 6. なぜ純粋性が重要か

純粋関数には参照透過性がある。

たとえば、

```haskell
square 3
```

は常に9なので、

プログラム中の

```haskell
square 3
```

を

```text
9
```

へ置き換えても意味が変わらない。

これにより関数合成が数学的に扱いやすくなる。

## 7. 型の別の見方

型を、

> 値の集合

と考えるだけでなく、

> どの計算とどの計算を接続できるかを指定するインターフェース

と考える。

この見方は非常に重要。
