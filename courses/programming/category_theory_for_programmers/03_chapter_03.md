# 第3章 圏のさまざま

圏の定義が極端に一般的であることを確認する。

## 1. Set

対象：

集合。

射：

関数。

最も基本的な圏。

## 2. 型の圏

対象：

型。

射：

純粋関数。

関数型プログラミングで最も重要。

## 3. 半順序集合

順序関係

\[
a\le b
\]

が成立するとき、

\[
a\to b
\]

という射があると考える。

## 合成

\[
a\le b,\quad b\le c
\]

なら、

\[
a\le c
\]

これは推移律。

つまり合成。

## 恒等射

\[
a\le a
\]

反射律。

## 4. モノイド

モノイドは、

- 二項演算
- 単位元
- 結合律

を持つ。

たとえば、

\[
(\mathbb Z,+,0)
\]

## 圏としてのモノイド

対象を1つだけにする。

```text
     *
   ↺ ↻ ↺
```

各モノイド要素を、

\[
*\to *
\]

という射と考える。

射の合成がモノイド演算になる。

## 5. なぜ重要なのか

後に、

> モナドは自己関手の圏におけるモノイド

という表現が出てくる。

したがって、

> 「モノイド＝リストのappendみたいなもの」

で終わらせず、

> **結合的な合成と単位元を持つ構造**

として理解する。
