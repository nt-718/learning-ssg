# 第13章 自由モノイド

## 1. 自由とは

「自由」は、

> 必要な構造だけを追加し、余計な関係を追加しない

という意味。

## 2. 集合からモノイドを作る

集合、

\[
A=\{a,b,\dots\}
\]

から、

\[
[],[a],[b],[a,a],[a,b],\dots
\]

を作る。

これがA上のリスト。

## 3. モノイド構造

演算：

```haskell
(++)
```

単位元：

```haskell
[]
```

## 4. なぜ自由なのか

元のAに、

\[
a=b
\]

などの余計な関係を追加しない。

唯一必要なのは、

リスト連結に伴うモノイド則。

## 5. 次章以降への伏線

自由構成は後に、

\[
Free\dashv Forgetful
\]

という随伴になる。

随伴を理解するための最重要具体例。
