# はじめに

## 0. この副読本の使い方

この副読本の目的は、圏論の用語を覚えることではない。

最終目標は、

> **「なぜその概念が必要になったのか」を説明できる状態**

になることである。

圏論では、定義だけを暗記すると非常に苦しくなる。

たとえば、

- 圏
- 関手
- 自然変換
- 表現可能関手
- 米田の補題
- 随伴
- モナド
- F-代数
- カン拡張

を別々の概念として覚えようとすると、ほぼ確実に途中で混乱する。

しかし実際には、

\[
\text{合成}
\rightarrow
\text{圏}
\rightarrow
\text{構造を保つ写像}
\rightarrow
\text{関手}
\rightarrow
\text{関手間の写像}
\rightarrow
\text{自然変換}
\]

という流れがある。

さらに、

\[
\text{普遍性}
\rightarrow
\text{極限}
\rightarrow
\text{表現可能性}
\rightarrow
\text{米田}
\rightarrow
\text{随伴}
\rightarrow
\text{モナド}
\]

という別の流れが合流する。

本書を読む際には、毎章次の5問を自分に投げる。

1. **この章では何を対象としているか。**
2. **射は何か。**
3. **何と何を合成しようとしているか。**
4. **どの構造を保存しているか。**
5. **この概念は次のどの概念の準備なのか。**

## 2. 最低限の数学記法

圏論を読むために高度な微積分や線形代数は必要ない。

必要なのは、記号への慣れである。

## 2.1 射

\[
f:A\to B
\]

は、

> f は A から B への射

と読む。

プログラミングなら、

```haskell
f :: A -> B
```

に近い。

## 2.2 合成

\[
g\circ f
\]

は、

> f を実行して、その結果に g を適用する

という意味。

順序に注意する。

\[
A\xrightarrow{f}B\xrightarrow{g}C
\]

なら、

\[
g\circ f:A\to C
\]

である。

Haskellでは、

```haskell
g . f
```

## 2.3 同型

\[
A\cong B
\]

は、

> A と B は構造的に同じ

という意味。

単なる値の等号

\[
A=B
\]

とは違う。

## 2.4 自然同型

\[
F\cong G
\]

と関手について書く場合、

単なる各対象ごとの同型ではなく、

> 関手の作用と整合する同型

であることが重要。
