# 第16章 米田埋め込み

## 1. 発想

各対象Aを、

\[
Hom(-,A)
\]

という関手として表現する。

## 2. Yoneda embedding

概略的に、

\[
Y:\mathcal C
\to
[\mathcal C^{op},Set]
\]

## 3. Fully faithful

米田埋め込みは元の圏の射の情報を失わない。

つまり、

> 対象を関手として表現しても、元の圏の関係構造を保持できる。

## 4. プログラマー向け直観

オブジェクトそのものを扱う代わりに、

> 「そのオブジェクトに対して可能な観測・操作」

をインターフェースとして扱っても、本質を失わないことがある。

## 第2部総整理

ここで、

```text
積
 ↓
普遍性
 ↓
極限
```

という流れと、

```text
Hom
 ↓
表現可能関手
 ↓
Yoneda
 ↓
Yoneda embedding
```

という流れを理解する。
