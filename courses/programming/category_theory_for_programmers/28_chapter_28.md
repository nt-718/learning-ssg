# 第28章 豊穣圏

## 1. 普通の圏

二つの対象A,Bについて、

\[
Hom(A,B)
\]

は集合。

## 2. 疑問

Homが単なる集合以上の構造を持っていたらどうなるか。

## 3. enriched category

Homを、

Setではなく別のモノイダル圏の対象として扱う。

## 4. 例：距離

距離空間を圏論的に扱うと、

AからBへの「射の情報」が、

実数値の距離として表現されるような構造を考えられる。

## 5. なぜ豊穣化するか

射の存在だけでなく、

- 距離
- 重み
- 順序
- 位相的情報

などをHomに持たせられる。
