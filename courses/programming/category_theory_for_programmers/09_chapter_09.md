# 第9章 関数型

## 1. 関数も型である

Haskellでは、

```haskell
A -> B
```

も一つの型。

## 2. 指数

有限集合について、

AからBへの関数の個数は、

\[
|B|^{|A|}
\]

なので、

\[
A\to B
\]

を、

\[
B^A
\]

と表す。

## 3. カリー化

\[
(A\times B)\to C
\]

と、

\[
A\to(B\to C)
\]

は対応する。

## Haskell

```haskell
curry
  :: ((a,b) -> c)
  -> a
  -> b
  -> c
```

## 4. デカルト閉圏

概略として、

- 終対象
- 二項積
- 指数対象

を持つ圏をデカルト閉圏という。

## 5. プログラミング上の意味

関数を値として扱えること、

高階関数を使えること、

カリー化できることが、

圏論上の構造として表される。

## 6. Curry–Howard

型と論理の対応。

| 型 | 論理 |
|---|---|
| \(A\times B\) | \(A\land B\) |
| \(A+B\) | \(A\lor B\) |
| \(A\to B\) | \(A\Rightarrow B\) |
| Void | False |
| Unit | True |

プログラムを、

> 命題の証明

として見る視点である。
