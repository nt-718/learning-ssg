# 第27章 カン拡張

圏論の「万能構成」と呼びたくなる概念。

## 1. 問題

関手、

\[
F:\mathcal C\to\mathcal E
\]

と、

\[
K:\mathcal C\to\mathcal D
\]

がある。

FをD上へ延長したい。

## 2. 図

```text
C ----F----> E
|
| K
v
D
```

DからEへの関手を作りたい。

## 3. Left Kan Extension

\[
Lan_KF
\]

は、

FをKに沿って延長する普遍的な方法。

## 4. Right Kan Extension

双対として、

\[
Ran_KF
\]

がある。

## 5. 「最適な近似」

Kによって情報が変換されるため、

完全な延長が存在しない場合がある。

そのとき、

> 普遍性によって最良の延長

を選ぶ。

## 6. なぜ重要なのか

多くの圏論的構成をKan extensionとして表現できる。

したがって、

> Kan extensionは非常に一般的な「普遍的な延長」の枠組み

と理解する。

## 7. 初学者向け理解

最初は数式を追うより、

```text
既知の構造
   ↓
別の世界へ移す
   ↓
できるだけ自然に延長
```

と捉える。
