# 第29章 トポス

この章では、

> Setに似た非常に豊かな圏

を扱う。

## 1. Setの特徴

集合の圏には、

- 有限極限
- 指数対象
- 部分集合
- 真偽値

などがある。

## 2. Subobject

部分集合の圏論版。

単射、

\[
S\hookrightarrow A
\]

を使って表す。

## 3. Subobject classifier

Setでは、

\[
\Omega=\{False,True\}
\]

を考える。

部分集合、

\[
S\subseteq A
\]

は、

特性関数、

\[
\chi_S:A\to\Omega
\]

として表せる。

## 4. 例

偶数集合なら、

```haskell
isEven :: Int -> Bool
```

## 5. Topos

大まかには、

> 集合の圏と似た論理的・構成的能力を持つ圏

と捉える。

## 6. 内部論理

Topos内部では独自の論理体系を考えられる。

すべての場合に古典論理になるとは限らない。

## 7. 重要な意味

「集合」と「論理」は別物ではなく、

圏論を通じて密接につながる。
