# 第60章 リファクタリングからパターンを発見する

最初からパターンを入れる必要はありません。

むしろ、

```text
素朴な実装
    ↓
問題発生
    ↓
重複・条件分岐増加
    ↓
責務を分析
    ↓
リファクタリング
    ↓
結果としてパターンになる
```

という順番が理想です。

## 例

最初：

```python
if payment == "card":
    ...
elif payment == "bank":
    ...
```

3種類程度なら問題ありません。

10種類になった。

さらに各方式で処理が20行ある。

そこで、

```python
PaymentStrategy
```

へ分離する。

これが自然なStrategy導入です。
