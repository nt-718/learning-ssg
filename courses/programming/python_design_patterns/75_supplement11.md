# 学習ロードマップ

## 概要

最初に優先して習得するなら、次の順番を推奨します。

```text
1. SOLID
2. Dependency Injection
3. Strategy
4. Factory
5. Adapter
6. Decorator
7. Observer
8. State
9. Command
10. Repository
11. Service Layer
12. Domain Events
13. Hexagonal Architecture
14. Clean Architecture
```

その後、

```text
Composite
Bridge
Proxy
Mediator
Visitor
Unit of Work
Specification
CQRS
Event Sourcing
```

へ進みます。

特にPythonでは、

```text
デザインパターン
        ×
Python言語機能
        ×
リファクタリング
        ×
アーキテクチャ
```

を一体として理解することが重要です。

これによって、

> 「GoFの23パターンを知っている」

という段階から、

> **コードを見て、変化・責務・依存関係を分析し、適切な構造へ設計し直せる**

という実践的な設計能力へ進むことができます。
