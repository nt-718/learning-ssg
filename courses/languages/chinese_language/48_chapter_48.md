# 第48章 発音・文法チェックリスト

## 発音

- [ ] 四声を手の動きなしでも区別できる
- [ ] 第3声を毎回V字にせず、半三声で読める
- [ ] `一・不` の変調を語の中で実行できる
- [ ] `b/p・d/t・g/k・j/q` を息の強さで区別できる
- [ ] `j/q/x・zh/ch/sh・z/c/s` を区別できる
- [ ] `an/ang・en/eng・in/ing` を区別できる
- [ ] `u/ü` を区別できる
- [ ] 軽声を短く弱く読める
- [ ] 一字ずつでなく、意味のまとまりで読める

## 文法

- [ ] 時間・場所・副詞・動詞の基本語順を作れる
- [ ] `是・有・在` を使い分けられる
- [ ] `不・没` を使い分けられる
- [ ] `会・能・可以` を使い分けられる
- [ ] 量詞を付けて名詞を数えられる
- [ ] `了・过・着・正在` の視点を説明できる
- [ ] 結果補語と可能補語を作れる
- [ ] `把・被` を必要なときに使える
- [ ] `的・地・得` を書き分けられる
- [ ] 条件・因果・逆接の複文を作れる
