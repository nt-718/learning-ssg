# 付録D 学習者用自己評価

## 資料

各項目を0～3で評価してください。

- 0：できない
- 1：見れば分かる
- 2：時間をかければ自力でできる
- 3：会話・作文で自然に使える

| 領域 | 評価項目 | 0～3 |
|---|---|---:|
| 発音 | 四声と軽声を区別して読める |  |
| 発音 | 主要な子音・鼻韻尾を区別できる |  |
| 聴解 | ゆっくりした自己紹介の要点が分かる |  |
| 聴解 | 日時・金額・場所を聞き取れる |  |
| 会話 | 1分間の自己紹介ができる |  |
| 会話 | 聞き返し・言い換えができる |  |
| 文法 | 基本語順で文を組み立てられる |  |
| 文法 | 了・过・着を使い分けられる |  |
| 文法 | 補語・把・被を使える |  |
| 読解 | 300字程度の文章の要点を取れる |  |
| 作文 | 日記を150字程度で書ける |  |
| 作文 | 意見文を300字程度で書ける |  |

0～1の項目を翌月の重点目標にします。合計点だけでなく、技能間の偏りを見てください。読めるが話せない場合は音声再生、話せるが書けない場合は短文作文、文法は分かるが聞けない場合は既習例文のディクテーションを増やします。
