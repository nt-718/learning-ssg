# 第17章 結果補語・方向補語

## 17.1 結果補語

動詞の後ろに結果を置き、「動作＋その結果」を一まとまりにします。

| 補語 | 意味 | 例 |
|---|---|---|
| 完 wán | 完了する | 吃完 食べ終える |
| 好 hǎo | うまく完了・準備 | 做好 作り上げる |
| 到 dào | 到達・獲得 | 找到 見つける |
| 见 jiàn | 知覚する | 看见 見える |
| 懂 dǒng | 理解する | 听懂 聞いて理解する |
| 错 cuò | 間違える | 写错 書き間違える |
| 清楚 qīngchu | 明瞭になる | 说清楚 はっきり説明する |
| 住 zhù | 固定・保持 | 记住 覚えておく |

> 我看完这本书了。私はこの本を読み終えました。  
> 我没听懂。私は聞いて理解できませんでした。

結果補語を含む動詞の否定には、多くの場合 `没` を使います。

## 17.2 単純方向補語

- 来：話し手・基準点へ近づく
- 去：話し手・基準点から遠ざかる

> 他进来了。彼は入ってきました。  
> 她出去了。彼女は出ていきました。

## 17.3 複合方向補語

| 方向 | 来 | 去 |
|---|---|---|
| 上る | 上来 | 上去 |
| 下る | 下来 | 下去 |
| 入る | 进来 | 进去 |
| 出る | 出来 | 出去 |
| 戻る | 回来 | 回去 |
| 通過する | 过来 | 过去 |
| 起き上がる | 起来 | — |

目的語が場所の場合、通常 `来／去` の前に置きます。

> 他走进教室来了。彼は教室へ歩いて入ってきました。

一般の物を表す目的語の位置は、情報構造や構文により変わります。

> 请拿一本书来。本を一冊持ってきてください。  
> 请把书拿来。その本を持ってきてください。

## 17.4 比喩的な方向

- 想起来：思い出す
- 看出来：見て分かる
- 坚持下去：続けていく
- 冷静下来：落ち着いてくる

### 章末問題17

1. ［初級］看＋完、听＋懂、写＋错の意味を答えてください。
2. ［初級］「彼は教室に入ってきました」を中国語にしてください。
3. ［初級］「このまま続けてください」を `下去` を使って表してください。

### 解答・解説17

1. 読み／見終える、聞いて理解する、書き間違える。
2. 他走进教室来了。／他进教室来了。
3. 请这样继续下去。／请坚持下去。
