# 第41章 日本語話者の誤りやすい点

## 41.1 是の過剰使用

- × 我是很忙。
- ○ 我很忙。

形容詞述語文に、英語のbe動詞や日本語の「です」の感覚で `是` を足しません。

## 41.2 的の過剰使用

- ○ 我妈妈
- 不自然になりやすい：我的妈妈（対比・強調なら可）
- ○ 汉语老师
- 意味が異なり得る：中国的老师（中国の先生）

## 41.3 了＝過去形という誤解

- 去年我常常去游泳。昨年、よく泳ぎに行った。
- 明天吃了饭再走。明日、食事を済ませてから行く。

`了` の有無は過去かどうかだけでは決まりません。

## 41.4 目的語を動詞の前に置く

日本語語順に引かれないようにします。

- × 我汉语学习。
- ○ 我学习汉语。
- 話題化なら可：汉语，我学了三年了。

## 41.5 「ある」と「いる」の直訳

- 所有・存在：有
- 所在地：在

> 桌子上有书。本が机の上にある。  
> 书在桌子上。その本は机の上にある。

## 41.6 能・会・可以の混同

- 技能：我会游泳。
- 条件：今天我不能游泳。
- 許可：这里可以游泳。

## 41.7 `和` を文接続に使いすぎる

`和` は主に名詞・名詞句を結びます。二つの文をつなぐときは、因果・逆接・並列などに応じて接続表現を選びます。

- × 因为下雨，和我没去。
- ○ 因为下雨，所以我没去。

## 41.8 日中同形語

| 中国語 | 中国語の意味 | 日本語とのずれ |
|---|---|---|
| 大丈夫 | 立派な男 | 「問題ない」ではない |
| 小心 | 注意する | 「気が小さい」ではない |
| 经理 | 経営管理者、マネージャー | 「経理」ではない |
| 老板 | 経営者、店主 | 板ではない |
| 意见 | 意見／不満 | 文脈により「異議」 |
| 紧张 | 緊張する／不足して逼迫 | 人だけに限らない |
| 便宜 | 安い／都合がよい | 「便利」は方便 |
| 方便 | 便利だ／都合がよい | 文脈により婉曲表現もある |
| 告诉 | 告げる、教える | 「告訴する」ではない |
| 审判 | 裁判する | 審判員一般ではない |

### 章末問題41

1. ［中級］我是很喜欢中国菜。
2. ［中級］我昨天不去公司。
3. ［中級］我可以说汉语。（習得した技能を言いたい）
4. ［中級］桌子在一本书。
5. ［中級］因为很忙，和我没参加会议。

### 解答・解説41

1. 我非常喜欢中国菜。
2. 我昨天没去公司。（事実の未実現を言う場合）
3. 我会说汉语。
4. 桌子上有一本书。
5. 因为很忙，所以我没参加会议。
