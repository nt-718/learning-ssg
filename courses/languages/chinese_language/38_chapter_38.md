# 第38章 口語と書面語

## 38.1 レジスター

同じ内容でも、友達との会話、業務メッセージ、報告書、ニュースでは語彙と文の組み立てが変わります。

| 口語寄り | 書面語寄り | 意味 |
|---|---|---|
| 为什么 | 为何 | なぜ |
| 怎么 | 如何 | どのように |
| 因为 | 由于 | ～のため |
| 所以 | 因此／因而 | したがって |
| 但是 | 然而／但 | しかし |
| 和／跟 | 与 | ～と |
| 现在 | 目前／当前 | 現在 |
| 马上 | 立即 | すぐに |
| 越来越 | 日益 | ますます |
| 觉得 | 认为 | ～と考える |

書面語を会話に混ぜすぎると堅く、口語を正式文書にそのまま使うと軽くなることがあります。

## 38.2 四字表現

中国語の書面では、四音節のまとまりが好まれます。

- 越来越多 → 日益增多
- 很有关系 → 密切相关
- 一起发展 → 共同发展
- 充分利用 → 十分に活用する
- 解决问题 → 問題を解決する

成語は意味だけでなく、使える主語・目的語・評価の方向まで確認します。

## 38.3 名詞化と動詞中心の文

日本語の公的文章は「～の実施」「～の確認」のような名詞化が多い一方、中国語では自然な動詞文にしたほうが明瞭なことがあります。

> 对需求进行确认。要件に対して確認を実施する。  
> 确认需求。要件を確認する。

`进行＋二音節動詞` は正式文で使われますが、乱用すると冗長です。

## 38.4 書面語の接続

- 首先／其次／最后：第一に／第二に／最後に
- 一方面……另一方面……：一方で～、他方で～
- 此外：さらに
- 与此同时：それと同時に
- 总之／综上所述：要するに／以上をまとめると

### 章末問題38

1. ［中級］因为用手机的人越来越多，所以这个服务很重要。
2. ［中級］我们得马上解决这个问题。
3. ［中級］你怎么看这个结果？

### 解答・解説38

1. 由于手机用户日益增多，因此该服务十分重要。
2. 我们必须立即解决这一问题。
3. 您如何看待这一结果？／您认为这一结果说明了什么？
