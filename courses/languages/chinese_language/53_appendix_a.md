# 付録A 中国語の句読点

## 資料

| 記号 | 名称 | 用法 |
|---|---|---|
| `，` | 逗号 dòuhào | 文中の区切り |
| `。` | 句号 jùhào | 文末 |
| `、` | 顿号 dùnhào | 語句の列挙 |
| `；` | 分号 fēnhào | 大きな並列 |
| `：` | 冒号 màohào | 説明・引用の導入 |
| `？` | 问号 wènhào | 疑問 |
| `！` | 叹号 tànhào | 感嘆 |
| `“ ”` | 引号 yǐnhào | 引用 |
| `《 》` | 书名号 shūmínghào | 書名・作品名 |
| `……` | 省略号 shěnglüèhào | 省略・余韻 |

列挙では、日本語の読点感覚で `、` と `，` を混同しないようにします。語の列挙には `、`、節や文の区切りには `，` を使います。
