# 第46章 重要量詞リファレンス

| 量詞 | 対象・用法 | 例 |
|---|---|---|
| 个 | 最も一般的 | 一个苹果、一个想法 |
| 位 | 敬意を伴う人 | 两位客人 |
| 名 | 名簿・正式な人員 | 三名员工 |

| 件 | 衣類・事柄 | 两件事 |
| 条 | 細長い物・項目 | 一条河、一条消息 |
| 根 | 棒状の物 | 一根线 |
| 把 | 柄のある物・ひとつかみ | 一把伞、一把椅子 |
| 双 | 対の物 | 一双筷子 |
| 对 | 一対・夫婦 | 一对夫妻 |

| 所 | 学校・病院・家屋 | 一所大学 |
