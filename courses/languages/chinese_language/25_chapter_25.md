# 第25章 あいさつ・自己紹介

## 25.1 基本表現

| 中国語 | ピンイン | 日本語 |
|---|---|---|
| 你好。 | Nǐ hǎo. | こんにちは |
| 您好。 | Nín hǎo. | こんにちは（丁寧） |
| 早上好。 | Zǎoshang hǎo. | おはようございます |
| 晚上好。 | Wǎnshang hǎo. | こんばんは |
| 再见。 | Zàijiàn. | さようなら |
| 明天见。 | Míngtiān jiàn. | また明日 |
| 谢谢。 | Xièxie. | ありがとう |
| 不客气。 | Bú kèqi. | どういたしまして |
| 对不起。 | Duìbuqǐ. | すみません |
| 没关系。 | Méi guānxi. | 大丈夫です |
| 不好意思。 | Bù hǎoyìsi. | すみません／恐縮です |

## 25.2 自己紹介の型

> 大家好，我叫中川。我来自日本，现在住在东京。我在一家IT公司工作，主要负责软件开发。我学习汉语是因为对中国的科技和文化很感兴趣。请多关照。  
> Dàjiā hǎo, wǒ jiào Zhōngchuān. Wǒ láizì Rìběn, xiànzài zhù zài Dōngjīng. Wǒ zài yì jiā IT gōngsī gōngzuò, zhǔyào fùzé ruǎnjiàn kāifā. Wǒ xuéxí Hànyǔ shì yīnwèi duì Zhōngguó de kējì hé wénhuà hěn gǎn xìngqù. Qǐng duō guānzhào.  
> 皆さん、こんにちは。中川といいます。日本出身で、現在は東京に住んでいます。IT企業で働き、主にソフトウェア開発を担当しています。中国のテクノロジーと文化に興味があるため、中国語を学んでいます。よろしくお願いします。

中国語の `请多关照` は日本語の「よろしくお願いします」の訳として使えますが、あらゆる場面で機械的に対応する万能表現ではありません。依頼なら `麻烦你了`、今後の協力なら `希望今后合作愉快` など、目的に合う表現を選びます。

## 25.3 会話

> A：你好，我叫王明。你叫什么名字？  
> B：我叫田中。很高兴认识你。  
> A：我也很高兴认识你。你是哪国人？  
> B：我是日本人。你呢？  
> A：我是中国人，来自上海。
