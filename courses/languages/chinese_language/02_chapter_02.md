# 第2章 声母・韻母と日本語話者の難所

## 2.1 声母一覧

| グループ | 声母 | 発音上の要点 |
|---|---|---|
| 唇音 | b p m f | b/pは無声。違いは息の強さ |
| 舌尖中音 | d t n l | d/tも息の強さで区別 |
| 舌根音 | g k h | hは日本語より摩擦が強い |
| 舌面音 | j q x | 舌面を上あごに近づける |
| そり舌音 | zh ch sh r | 舌先をやや後方へそらす |
| 舌歯音 | z c s | 舌先を上の歯の裏付近へ |

中国語の `b/d/g` は、日本語の濁音「バ・ダ・ガ」と同じではありません。普通話の対立は主として有気音と無気音です。

- `b d g j zh z`：息を強く出さない無気音
- `p t k q ch c`：息を強く出す有気音

薄い紙を口の前に置き、有気音で大きく揺れるか確かめると効果的です。

## 2.2 特に区別すべき子音

### j・q・x

舌先を下の前歯の裏に置き、舌の中央を硬口蓋に近づけます。

- 鸡 `jī`：鶏
- 七 `qī`：七
- 西 `xī`：西

`j/q/x` の後ろに書かれる `u` は、実際には多くの場合 `ü` です。

- 去 `qù` = q + ü
- 学 `xué` = x + üe

### zh・ch・sh・r と z・c・s

| そり舌音 | 舌歯音 | 例 |
|---|---|---|
| zhī 知 | zī 资 | 知る／資源の資 |
| chī 吃 | cī 疵 | 食べる／欠点 |
| shī 师 | sī 丝 | 教師／糸 |

`r` は日本語のラ行ではありません。舌をそらし、声帯を振動させながら摩擦を作ります。

### n と ng

- `an/en/in`：舌先が上歯茎に触れる
- `ang/eng/ing`：舌の奥が上がり、舌先は触れない

例：`jīn 金` と `jīng 京`、`chén 陈` と `chéng 成`

## 2.3 主な韻母

### 単母音

`a, o, e, i, u, ü`

- `e` は日本語の「エ」ではなく、口を軽く開けて奥で響かせる
- `ü` は「イ」の舌位置のまま唇を丸める

### 複合韻母

`ai, ei, ao, ou, ia, ie, ua, uo, üe, iao, iou(iu), uai, uei(ui)`

### 鼻韻母

`an, en, ang, eng, ong, ian, in, iang, ing, iong, uan, uen(un), uang, ueng, üan, ün`

## 2.4 `i` の三種類

表記上は同じ `i` でも、発音は同じではありません。

- `ji/qi/xi` の i：通常の「イ」に近い
- `zhi/chi/shi/ri` の i：そり舌の構えを保つ
- `zi/ci/si` の i：舌歯音の構えを保つ

## 2.5 綴りの省略規則

- `iou → iu`：六 `liù`
- `uei → ui`：贵 `guì`
- `uen → un`：论 `lùn`
- `ü` は `j/q/x/y` の後で点を省く：鱼 `yú`、去 `qù`
- `n/l` の後では点を残す：女 `nǚ`、绿 `lǜ`

### 章末問題2

1. ［初級］`b` と `p` の主要な違いは何ですか。
2. ［初級］`qù` の `u` は実際にはどの母音ですか。
3. ［初級］`zh` と `z` は舌の形がどう違いますか。
4. ［初級］`nǚ` の `ü` の点を省略できない理由を説明してください。

### 解答・解説2

1. 主として息を強く出すかどうか。`b` は無気音、`p` は有気音。
2. `ü`
3. `zh` は舌先をやや後方へそらす。`z` は舌先を上歯の裏付近に置き、そらさない。
4. `n/l` の後ろでは `u` と `ü` の両方があり得るため、区別のため点を残す。
