# 第3章 声調変化・軽声・儿化

## 3.1 第3声の連続

第3声が二つ連続すると、前の第3声を第2声のように発音します。表記は変えません。

> 你好。  
> Nǐ hǎo.（発音上は ní hǎo に近い）  
> こんにちは。

三つ以上続く場合は、語のまとまりによって変化します。

- 我很好 `Wǒ hěn hǎo` → 通常「wó hén hǎo」に近い
- 我也很好 `Wǒ yě hěn hǎo` → 意味のまとまりを意識して読む

## 3.2 一の声調変化

`一 yī` は単独・語末・序数では原則第1声です。

- 一 `yī`：一
- 第一 `dì-yī`：第一

後ろが第4声なら第2声に変わります。

- 一个 `yí ge`
- 一样 `yíyàng`

後ろが第1・2・3声なら第4声に変わります。

- 一天 `yì tiān`
- 一年 `yì nián`
- 一起 `yìqǐ`

## 3.3 不の声調変化

`不 bù` は、後ろが第4声のとき第2声になります。

- 不是 `bú shì`
- 不去 `bú qù`
- 不吃 `bù chī`

## 3.4 軽声

軽声は短く弱く発音し、単語や文法的機能を区別することがあります。

- 妈妈 `māma`：お母さん
- 朋友 `péngyou`：友達
- 东西 `dōngxi`：物
- 认识 `rènshi`：知っている
- 这个 `zhège`：これ

辞書で軽声になっている語は、声調を機械的に強く読まないようにします。

## 3.5 儿化

北方の口語では、音節末に `儿 -r` が加わることがあります。

- 这儿 `zhèr`：ここ
- 那儿 `nàr`：そこ、あそこ
- 一点儿 `yìdiǎnr`：少し
- 玩儿 `wánr`：遊ぶ

儿化は語感や意味に影響することがありますが、初級段階では聞いて分かれば十分です。すべての語に付けてはいけません。

## 3.6 文全体のリズム

中国語を一字ずつ同じ強さで読むと不自然です。内容語は比較的強く、文法語は軽く、意味のまとまりの境界で短く区切ります。

> 我明天 / 想跟朋友 / 去北京看电影。  
> Wǒ míngtiān / xiǎng gēn péngyou / qù Běijīng kàn diànyǐng.  
> 私は明日／友達と／北京へ映画を見に行きたいです。

### 章末問題3

1. ［初級］你好
2. ［初級］一个
3. ［初級］一年
4. ［初級］不是
5. ［初級］不来

### 解答・解説3

1. `ní hǎo` に近い。第3声が連続するため、前が第2声化。
2. `yí ge`。後ろが第4声なので `一` は第2声。
3. `yì nián`。後ろが第2声なので `一` は第4声。
4. `bú shì`。後ろが第4声なので `不` は第2声。
5. `bù lái`。後ろが第2声なので変調しない。
