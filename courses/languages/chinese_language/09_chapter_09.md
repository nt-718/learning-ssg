# 第9章 量詞と数量表現

## 9.1 基本構造

中国語で名詞を数えるときは、通常 `数詞＋量詞＋名詞` の形にします。

> 三本书 `sān běn shū` 3冊の本  
> 两杯咖啡 `liǎng bēi kāfēi` 2杯のコーヒー

## 9.2 よく使う名量詞

| 量詞 | 主な対象 | 例 |
|---|---|---|
| 个 ge | 人・物一般 | 一个人、一个问题 |
| 位 wèi | 人への敬意 | 一位老师 |
| 本 běn | 本・冊子 | 一本词典 |
| 张 zhāng | 平たい物・張る物 | 一张纸、一张桌子 |
| 件 jiàn | 衣服・事柄 | 一件衣服、一件事 |
| 条 tiáo | 細長い物 | 一条路、一条鱼 |
| 杯 bēi | カップ・グラス | 一杯茶 |
| 瓶 píng | 瓶 | 一瓶水 |
| 辆 liàng | 車両 | 一辆车 |
| 家 jiā | 店・会社・家族 | 一家公司 |
| 间 jiān | 部屋 | 一间房 |
| 台 tái | 機械・設備 | 一台电脑 |
| 部 bù | 映画・大型作品・機器 | 一部电影 |
| 双 shuāng | 対の物 | 一双鞋 |
| 只 zhī | 動物・片方 | 一只猫、一只手 |

## 9.3 動量詞

動作の回数を表します。

- 次 `cì`：回数一般
- 遍 `biàn`：初めから終わりまで一通り
- 下 `xià`：短い動作、試しに
- 趟 `tàng`：往復・出かける回数

> 我去过两次北京。私は北京へ2回行ったことがあります。  
> 请再说一遍。もう一度最初から言ってください。  
> 你看一下。ちょっと見てください。  
> 我去一趟银行。銀行へひと走り行きます。

## 9.4 おおよその数量

- 三四个人：3、4人
- 十几本书：十数冊
- 几十家公司：数十社
- 两百多块：200元余り
- 左右：前後
