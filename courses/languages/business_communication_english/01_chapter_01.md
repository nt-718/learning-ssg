# 第1章 ビジネス英語とは何か

## 1.1 「英語力」と「ビジネスコミュニケーション力」は違う

英語のテストで高得点を取れる人でも、実務では次のような問題を起こすことがあります。

- 何を依頼しているのか分からない
- 期限が書いていない
- 誰が担当するのか不明
- 結論が最後まで出てこない
- 事実と推測が混ざっている
- 丁寧すぎて要求が分からない
- 相手の質問に答えていない

つまり、

> grammatical correctness ≠ communication effectiveness

です。

「文法的に正しいこと」と「コミュニケーションとして優れていること」は別物です。

## 1.2 ビジネスコミュニケーションの基本構造

仕事上のメッセージは、基本的に次の5要素で考えると整理できます。

### 1. Context
何について話しているか。

### 2. Message
最も伝えたい内容。

### 3. Reason
理由・背景。

### 4. Action
誰に何をしてほしいか。

### 5. Deadline
いつまでか。

例えば、

> Regarding the new website, we need to finalize the design this week because development starts next Monday. Could you review the attached mockup and send me your comments by Thursday?

なら、

Context  
→ new website

Message  
→ finalize the design this week

Reason  
→ development starts Monday

Action  
→ review the mockup / send comments

Deadline  
→ Thursday

となります。

## 1.3 「伝える」より「動かす」

日常英語では、

> I think this design is better.

でも成立します。

しかしビジネスでは、

> I recommend using Design B because it makes the main call-to-action more visible. If there are no objections, I'd like to proceed with Design B.

のように、

**意見 → 理由 → 次のアクション**

まで示す方が仕事が進みます。

## 1.4 ビジネスコミュニケーションの7機能

ほぼすべての業務コミュニケーションは、次の機能に整理できます。

### Inform
情報提供

> The release date has been changed to September 15.

### Request
依頼

> Could you review the document?

### Confirm
確認

> Just to confirm, the meeting starts at 2 p.m., correct?

### Clarify
明確化

> Could you clarify what you mean by "real-time"?

### Persuade
説得

> I believe this option gives us the best balance between cost and speed.

### Coordinate
調整

> I'll handle the technical side. Could you coordinate with the client?

### Resolve
問題解決

> Let's identify the cause first and then discuss possible solutions.

### 章末問題1

1. ［実務基礎］次の英文に不足している情報を指摘してください。／Please check the document.
2. ［実務基礎］次のメッセージを仕事が進む形にしてください。／We have a problem.
3. ［実務基礎］以下を英訳してください。／「最新版の資料を金曜日までに確認し、問題があれば教えてください。」
4. ［実務基礎］以下の英文の目的を分類してください。／Could you clarify what you mean by “high priority”?
5. ［実務基礎］次の英文を改善してください。／Maybe there is some issue and perhaps we should check.
6. ［実務基礎］次のメッセージにAction Itemを追加してください。／The design is almost complete.
7. ［実務基礎］「事実」と「推測」を分けて英文を書いてください。／事実：／昨日午後3時にサーバーが停止した。／推測：／原因はネットワーク設定の可能性がある。
8. ［実務基礎］以下をBLUF型に変更してください。／We have discussed several options, and there are still some technical concerns, and after considering the development schedule, we think that it might be better to postpone the launch.
9. ［実務基礎］次の英文が曖昧な理由を説明してください。／Please send it soon.
10. ［実務基礎］以下の状況で2文の英文を書いてください。／「顧客に仕様書の確認を依頼する。締切は水曜日。」

### 解答・解説1

1. 対象、確認内容、期限、確認後の行動が不明。
2. We identified an issue with the payment system. Our engineering team is investigating it and will provide an update by 3 p.m.
3. Could you review the latest version of the document by Friday and let me know if you find any issues?
4. Clarify
5. We may have an issue. I suggest checking the system logs first.
6. The design is almost complete. Could you review the latest version by tomorrow?
7. The server stopped at 3 p.m. yesterday. We believe the issue may have been caused by a network configuration problem.
8. We recommend postponing the launch because several technical issues remain unresolved.
9. soonの具体的期限がない。
10. Could you review the specification document? If possible, please send me your comments by Wednesday.
