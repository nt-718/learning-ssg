# はじめに

本書は、FP（ファイナンシャル・プランニング）技能検定3級の初学者が、基礎を理解したうえで2級まで進むための教科書である。単なる暗記表ではなく、「誰の、どの資金を、いつまでに、どの程度の確実性で準備するのか」というFPの考え方を軸に、制度・税・金融商品・保険・不動産・相続をつなげて説明する。

試験では制度の細かな数字も問われるが、数字だけを覚えると改正や応用問題に弱い。まず仕組みを理解し、次に計算式、最後に期限・年齢・金額を覚える。本書では、3級で必須の内容を「基礎」、2級で必要な例外・計算・比較を「2級への深掘り」として整理した。

> 【重要】本書の制度数値は、原則として2026年4月1日に施行済みの法令を基準とする。日本FP協会の2026年度CBT試験では、2026年4・5月実施分は2025年4月1日、2026年6月以降の実施分は2026年4月1日が法令基準日である。受検月の基準日は必ず公式サイトで再確認すること。本書は試験学習用であり、個別の金融・税務・法律上の助言ではない。

## 本書の使い方

1. 3級受検前は、各章の本文・「基本式」・章末問題の［3級］を優先する。
2. 3級合格後は、同じ章を再読し、「2級への深掘り」と［2級］問題を解く。
3. 間違えた問題は、正解だけでなく「なぜ他の選択肢が誤りか」を説明できるようにする。
4. 実技では電卓操作と資料読解が得点源になる。第8章を最低3周する。
5. 試験直前は第9章の数値・公式一覧と、自分の誤答だけを復習する。
6. 本文を一巡したら第11章の追加96問を解き、75％未満の分野だけ本文へ戻る。

## 30秒で見る全体像

| 分野 | 中心となる問い | 代表的な計算・論点 |
|---|---|---|
| ライフプランニング | 将来いくら必要か、公的保障はいくらか | 6係数、可処分所得、住宅ローン、年金 |
| リスク管理 | 不測の事態を何で補うか | 必要保障額、生命保険、損害保険、第三分野 |
| 金融資産運用 | リスクと収益をどう組み合わせるか | 利回り、債券価格、株式指標、投信、NISA |
| タックスプランニング | 所得をどう分類し税額を求めるか | 10所得、損益通算、所得控除、税額控除 |
| 不動産 | 権利・取引・税・収益性をどう読むか | 登記、宅建業法、建築基準法、譲渡所得 |
| 相続・事業承継 | 誰がどれだけ承継し、税をどう計算するか | 法定相続分、遺留分、相続税、贈与税 |
