## 9-3　必須公式

| テーマ | 公式 |
|---|---|
| 可処分所得 | 年収−所得税−住民税−社会保険料 |
| 純資産 | 資産合計−負債合計 |
| 複利終価 | 元本×（1＋利率）^年数 |
| PER | 株価÷EPS |
| PBR | 株価÷BPS |
| ROE | 当期純利益÷自己資本×100 |
| 債券最終利回り | ｛利息＋（額面−購入価格）÷残存年数｝÷購入価格×100 |
| 建蔽率 | 建築面積÷敷地面積×100 |
| 容積率 | 延べ面積÷敷地面積×100 |
| NOI利回り | NOI÷投資額×100 |
| 退職所得控除（20年超） | 800万円＋70万円×（勤続年数−20年） |
| 相続税基礎控除 | 3,000万円＋600万円×法定相続人 |

## 9-4　誤りやすい対比

| A | B | 区別 |
|---|---|---|
| 所得控除 | 税額控除 | 税率の前に引く／税率の後に引く |
| 収入 | 所得 | 入ってきた総額／経費・法定控除後 |
| TTS | TTB | 円で外貨を買う／外貨を円で売る |
| 建蔽率 | 容積率 | 建築面積／延べ面積 |
| 相続放棄 | 遺産分割で取得ゼロ | 初めから相続人でない／相続人のまま |
| 払済保険 | 延長保険 | 期間維持・金額減／金額維持・期間短縮 |
| 元利均等 | 元金均等 | 返済額一定／元金部分一定 |
| 普通分配金 | 元本払戻金 | 収益で課税／元本返還で非課税 |
