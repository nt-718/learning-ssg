# 16週間の学習計画

## 週間計画

| 週 | 範囲 | 学習課題 |
|---:|---|---|
| 1 | 第1章 | 統計・恒等式・因果の区別を自分の例で説明 |
| 2 | 第2章 | GDP三面、実質化、貯蓄投資恒等式を計算 |
| 3 | 第3～4章 | 資金循環・国際収支・労働統計を実データで確認 |
| 4 | 第5～6章 | 45度線、乗数、IS–LMを手で導出 |
| 5 | 第7章 | AD–ASとフィリップス曲線のショック分析 |
| 6 | 第8章 | 新しいケインジアン3本式を言葉で説明 |
| 7 | 第9章 | 為替の定義、PPP、UIP、政策レジーム比較 |
| 8 | 第10～11章 | 労働市場とソローモデルの定常状態計算 |
| 9 | 復習 | 総合問題1～6を資料なしで解く |
| 10 | 第12章 | 需要・供給・金融危機別の政策表を作る |
| 11 | 第13章 | 債務比率式、リカード命題、年金を整理 |
| 12 | 第14章 | 代表的個人と異質家計の結論差を説明 |
| 13 | 第15章 | 債券価格、期間構造、中央銀行BSを計算・作図 |
| 14 | 第16章 | 消費オイラー式、NPV、使用者費用、qを演習 |
| 15 | 第17～18章 | マッチングとラムゼー・内生成長を整理 |
| 16 | 総復習 | 総合問題7～12、弱点章の再演習、1ページ要約 |

### 1章ごとの合格基準

- 重要概念を資料なしで3分説明できる。
- 中心式を前提から導出できる。
- 横軸・縦軸・曲線のシフトと曲線上の移動を区別できる。
- 政策効果を短期・中期・長期に分けられる。
- モデルが省略した要素を2つ挙げられる。
- 統計から因果を断定しない理由を説明できる。
