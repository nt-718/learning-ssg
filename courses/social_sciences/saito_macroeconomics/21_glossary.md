# 重要概念ミニ辞典

## 重要概念一覧

| 用語 | 要点 |
|---|---|
| GDP | 国内で一定期間に生産された最終財・サービスの付加価値 |
| GNI | 居住者が得た第一次所得を基準にした国民概念 |
| 名目値 | 当期価格で評価した金額 |
| 実質値 | 価格変化を除いて数量変化を表す値 |
| ストック | 一時点の残高 |
| フロー | 一定期間の発生量 |
| 在庫投資 | 在庫残高の増加。意図しない増加も当期投資 |
| 経常収支 | 貿易・サービス、第一次所得、第二次所得の収支 |
| 対外純資産 | 居住者の対外資産から対外負債を引いた残高 |
| 失業率 | 失業者／労働力人口 |
| 労働力率 | 労働力人口／対象人口 |
| 潜在GDP | インフレを加速させず持続的に生産できる推計上の水準 |
| GDPギャップ | 実際GDPと潜在GDPの乖離 |
| 限界消費性向 | 可処分所得1増加のうち消費に回る額 |
| 乗数 | 外生支出1単位が均衡所得を変える倍率 |
| IS曲線 | 財市場を均衡させる所得と金利の組合せ |
| LM曲線 | 貨幣市場を均衡させる所得と金利の組合せ |
| 総需要 | 各物価・インフレ率に対応する需要・産出関係 |
| 総供給 | 産出と物価・インフレの供給側関係 |
| 自然失業率 | 賃金・価格設定が整合する中期的失業率。制度で変わる |
| フィリップス曲線 | インフレ、期待、需給、供給ショックの関係 |
| 自然利子率 | 価格伸縮的な潜在産出と整合する実質金利 |
| テイラー原理 | インフレ上昇以上に名目金利を上げ実質金利を上げる原則 |
| 実効下限 | 政策名目金利を十分下げられない下限 |
| 名目為替レート | 2通貨の交換比率。定義方向に注意 |
| 実質為替レート | 国内外財の相対価格を為替で調整した指標 |
| 交易条件 | 輸出価格／輸入価格 |
| 購買力平価 | 為替が国内外物価比と対応するという関係 |
| 金利平価 | 内外資産収益率と予想為替変化・リスクの関係 |
| トリレンマ | 固定相場、資本自由、金融政策独立の3つは同時達成不可 |
| マッチング関数 | 失業者と求人から成立する雇用の関係 |
| 効率賃金 | 努力・定着・選抜のため市場清算以上に払う賃金 |
| モノプソニー | 買い手側、労働市場では企業が賃金決定力を持つ状態 |
| ソロー残差 | 資本・労働寄与で説明できない成長。純粋技術だけではない |
| 定常状態 | 主要な1人当たり・効率単位当たり変数が一定の状態 |
| 黄金律 | 定常消費を最大化する資本水準 |
| 条件付き収束 | 構造条件が同じ国ほど同じ定常状態へ近づくこと |
| 自動安定化装置 | 税・給付が裁量決定なしに景気変動を緩和する仕組み |
| クラウディングアウト | 公的需要が金利・資源・為替を通じ民間需要を押し出すこと |
| 基礎的財政収支 | 利払費を除く政府収支 |
| リカードの中立命題 | 国債減税が将来増税予想で消費を変えないという条件付き命題 |
| ルーカス批判 | 政策変更で期待と行動式が変わり、過去の集計関係が不変でない |
| 合理的期待 | 利用可能情報に対する系統的な予測誤差を残さない期待 |
| オイラー方程式 | 隣接時点の限界便益を結ぶ最適化条件 |
| 代表的個人 | 異質な主体を1主体で代表させる単純化 |
| 予備的貯蓄 | 保険できない将来リスクに備えた貯蓄 |
| 流動性制約 | 将来所得を担保に十分借りられない制約 |
| 使用者費用 | 資本保有の金利・減耗・価格変化を含む費用 |
| トービンのq | 企業価値と資本再取得費用の比率 |
| 期間プレミアム | 長期債保有の金利・インフレ等リスクへの補償 |
| 金融加速器 | 純資産・担保・スプレッドが実体ショックを増幅する仕組み |
| 時間非整合性 | 事前に望ましい約束を事後に破る誘因が生じること |
| 動学的効率性 | 資本を減らして全世代の消費を増やせない状態 |
| 人的資本 | 教育、技能、経験、健康に体化した生産能力 |
| 創造的破壊 | 新技術・企業が旧技術・企業を置き換える革新過程 |
| ミスアロケーション | 資源が限界生産性の高い用途へ十分移らない状態 |
| 反実仮想 | 実際とは異なる政策・出来事のもとでの仮想結果 |
