# はじめに

## 統計・理論・政策を一本の線で理解するための学習参考書



## はじめに

本書は、齊藤誠・岩本康志・太田聰一・柴田章久『マクロ経済学 新版』（有斐閣、2016年、ISBN 978-4-641-05384-7）を学ぶ読者のための**独立した副読本**である。原著の文章、図表、設問を転載・要約するものではない。原著の章構成に対応させながら、標準的なマクロ経済理論を別の説明、数式の導出、具体例、注意点、演習問題によって再構成した。

原著は、国民経済計算などの統計を丁寧に扱ったうえで、短期・中期・長期のモデル、経済政策、ミクロ的基礎づけへ進む。本副読本もこの順序を尊重する。マクロ経済学では、観測された数字、会計上必ず成り立つ関係、主体の行動を表す仮説、市場均衡、政策評価を混ぜないことが最も重要だからである。

## 本副読本の使い方

### 基本の学習サイクル

1. 原著の該当章を読み、わからない語句と式に印をつける。
2. 本副読本の「到達目標」と本文の流れを確認する。
3. 数式を紙に書き、各変数の単位と符号を言葉で説明する。
4. 「具体例」と「統計を読む視点」で、モデルと現実を往復する。
5. 理解度確認問題を資料なしで解く。
6. 解答を読んだ後、自分の誤りが「定義」「計算」「因果」「時間軸」のどれだったか記録する。

### 全章で区別すべき5つの層

| 層 | 問い | 例 |
|---|---|---|
| 定義 | その概念を何と呼ぶか | GDP、失業者、実質金利 |
| 会計 | 記録上、必ず成り立つか | `Y = C + I + G + NX` |
| 行動 | 人や企業はどう反応するか | 金利上昇で投資が減る |
| 均衡 | 複数の行動が両立する値は何か | 財市場と貨幣市場の同時均衡 |
| 規範 | 何が望ましいか | インフレ安定と景気安定の配分 |

恒等式は因果を示さない。たとえば、事後的に貯蓄と投資が一致していても、「貯蓄が増えたから投資が増えた」とは限らない。価格、所得、金利などが調整した結果として一致した可能性がある。

### モデルを読む7つの質問

1. 内生変数は何か。
2. 外生変数は何か。
3. 短期・中期・長期のどれか。
4. 価格や賃金は調整するか。
5. 期待は静学的か、適応的か、合理的か。
6. 閉鎖経済か開放経済か。
7. 政策変更は一時的か恒久的か、予想済みか予想外か。


## 記号一覧

| 記号 | 意味 |
|---|---|
| `Y` | 実質GDP・産出量・所得 |
| `C` | 民間消費 |
| `I` | 投資 |
| `G` | 政府購入 |
| `T` | 租税（文脈により純租税） |
| `X, M, NX` | 輸出、輸入、純輸出 |
| `S` | 貯蓄 |
| `K` | 資本ストック |
| `L, N` | 労働投入・雇用量 |
| `A` | 技術水準・全要素生産性 |
| `P` | 物価水準 |
| `\pi` | インフレ率 |
| `i` | 名目金利 |
| `r` | 実質金利 |
| `M` | 名目貨幣残高（輸入と同じ記号なので文脈に注意） |
| `E` | 名目為替レートまたは期待演算子。定義を必ず確認する |
| `q` | 実質為替レートまたはトービンのq |
| `w, W` | 実質賃金、名目賃金 |
| `u` | 失業率 |
| `B` | 政府債務・債券 |
| `\delta` | 資本減耗率 |
| `\rho, \beta` | 時間選好率、割引因子 |
