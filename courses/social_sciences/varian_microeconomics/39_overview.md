# 付録A 全体の見取り図

ヴァリアンの全38章は、ばらばらの論点ではなく、次の依存関係を持つ。

| 段階 | 中心章 | 核となる問い |
|---|---|---|
| 市場の入口 | 1 | 価格と配分はどう決まるか |
| 消費者理論 | 2–8 | 制約下で何を選び、価格変化にどう反応するか |
| 資産・不確実性 | 9–13 | 保有、時間、危険をまたぐ選択はどう決まるか |
| 市場需要と実証 | 14–18 | 個人を集計し、厚生・因果・制度をどう測るか |
| 生産者理論 | 19–24 | 技術から費用、供給、参入をどう導くか |
| 不完全競争 | 25–31 | 市場支配力と戦略的相互作用は結果をどう変えるか |
| 一般均衡と厚生 | 32–34 | 市場全体の整合性、効率、公平をどう考えるか |
| 市場の失敗と制度 | 35–38 | 外部性、公共財、ネットワーク、情報問題をどう改善するか |

## 同じ構造の対応関係

| 消費者理論 | 生産者理論 | 共通構造 |
|---|---|---|
| 効用関数 | 生産関数 | 目的・技術の表現 |
| 無差別曲線 | 等量曲線 | 同じ成果を与える組合せ |
| 予算線 | 等費用線 | 市場価格による制約 |
| $MRS=p_1/p_2$ | $TRS=w_1/w_2$ | 主体内の交換比率＝市場交換比率 |
| 効用最大化需要 | 費用最小化要素需要 | 制約付き最適化 |
| 間接効用関数 | 費用関数 | 最適化後の価値関数 |
| 顕示選好 | 顕示利潤・顕示費用最小化 | 観察された選択の整合性 |
