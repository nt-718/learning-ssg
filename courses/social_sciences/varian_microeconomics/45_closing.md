# おわりに

ミクロ経済学の問題は、対象が消費、企業、金融、情報、環境へ変わっても、基本的には次の問いへ戻せる。

1. 誰が意思決定しているか。
2. その人の目的は何か。
3. 何が制約になっているか。
4. 何を所与とし、何が内生的に決まるか。
5. 個々の最適化は市場全体で両立するか。
6. 均衡は効率的か、公平か。
7. 情報、外部性、戦略、制度を加えると結論はどう変わるか。

公式を忘れても、この七つを順に問えば、多くのモデルを自力で再構成できる。教科書の図・例・章末問題と本参考書の独自問題を往復し、「解答を再現する」段階から「仮定を変えたときの結果を予測する」段階へ進むことが最終目標である。
