# 付録F 頻出の混同を一括整理

## 混同しやすい概念一覧

| 混同しやすい組 | 違い |
|---|---|
| 需要量の変化／需要の変化 | 前者は曲線上の移動、後者は曲線のシフト |
| 正常財／通常財 | 正常財は所得反応、通常財は自己価格反応 |
| 下級財／ギッフェン財 | 下級財のうち所得効果が代替効果を上回る特殊例がギッフェン財 |
| 序数効用／基数効用 | 順位だけを表すか、差にも意味を持たせるか |
| 代替効果／所得効果 | 相対価格変化への反応か、購買力変化への反応か |
| 総需要／純需要 | 最終保有量か、初期保有からの売買量か |
| 名目利子率／実質利子率 | 貨幣額の増加率か、購買力の増加率か |
| 期待値／確実性等価 | 平均金額か、同じ期待効用を与える確実額か |
| 固定費／埋没費用 | 産出量に依存しない費用か、現在回収不能な過去費用か |
| 生産者余剰／利潤 | 前者は収入−可変費、後者は収入−総費用 |
| 操業停止／退出 | 短期に生産を止めるか、長期に市場から去るか |
| 会計利益／経済利潤 | 明示費用だけを引くか、機会費用も引くか |
| 独占利潤／死荷重 | 余剰の移転か、取引減少で消滅した余剰か |
| ナッシュ均衡／社会最適 | 個別逸脱が得でない状態か、全体として望ましい状態か |
| リスク／不確実性 | 確率分布を扱える変動か、確率自体も不明な状況か |
| 効率性／公平性 | 改善余地の有無か、分配の望ましさか |
| 外部性／公共財 | 第三者効果か、非競合・非排除という財の性質か |
| 逆選択／モラルハザード | 契約前の隠れた属性か、契約後の隠れた行動か |
| シグナリング／スクリーニング | 情報保有側が示すか、非保有側が選別するか |
