# 付録C 問題を解くための標準手順

## 1. 消費者の最適化

1. 効用関数と予算制約を書く。
2. 選好の型を確認する：滑らか、完全代替、完全補完、準線形、離散財。
3. 滑らかな内点候補なら$MRS=p_1/p_2$と予算等式を連立する。
4. 非負制約と端点を確認する。
5. 候補が複数なら効用値を比較する。
6. 単位、予算消化、価格・所得変化への直観を確認する。

## 2. 企業の最適化

1. 市場構造を特定する：価格受容か価格設定者か。
2. 利潤を「収入−費用」で明示する。
3. 競争企業なら$p=MC$、独占なら$MR=MC$で候補を求める。
4. 操業停止・退出条件、能力制約、非負制約を確認する。
5. 数量を需要関数へ代入して価格を求める。
6. 利潤と余剰を混同せず計算する。

## 3. 政策分析

1. 政策前の均衡を求める。
2. 政策が曲線を動かすのか、価格のくさびを作るのかを特定する。
3. 政策後の買い手価格、売り手価格、数量を分けて求める。
4. 消費者余剰、生産者余剰、政府収入、外部便益・損害を整理する。
5. 総余剰変化と分配変化を分ける。
6. 短期と長期、情報・執行費用も検討する。

## 4. ゲーム理論

1. プレイヤー、戦略、利得、手番、情報を列挙する。
2. 同時手番なら各プレイヤーの最適反応を求める。
3. 最適反応の交点からナッシュ均衡を得る。
4. 逐次手番なら最後から後ろ向きに解く。
5. 均衡外で実行される脅しが本当に最適か確認する。
6. 反復なら、現在の逸脱利益と将来の罰の現在価値を比較する。

## 5. 図を描くときの確認事項

- 軸の変数と単位を書く。
- 曲線上を動くのか、曲線がシフトするのかを分ける。
- 傾きと切片を式から確認する。
- 初期均衡と新均衡を別記号で示す。
- 税、外部費用、独占では価格・限界収入・限界費用のどこに「くさび」があるか示す。
- 面積を余剰として読むとき、底辺と高さの経済的意味を書く。
