## はじめに

本書は、ハル・R・ヴァリアン『入門ミクロ経済学［原著第9版］』の全38章に対応した学習参考書である。章題と学習順序は日本語版に合わせているが、本文の説明、例題、章末問題、解答はすべて本参考書のために独自に構成した。

ヴァリアンの教科書は、個々の公式を暗記するよりも、次の三段階を往復しながら読むと理解しやすい。

1. **目的を特定する**：消費者、企業、政府など、誰が何を最大化・最小化しているか。
2. **制約を特定する**：予算、技術、情報、制度によって何が実行可能か。
3. **均衡を考える**：各主体の選択が、市場全体で同時に整合する価格・数量は何か。

### 本参考書の使い方

各章は、次の順番で学ぶことを推奨する。

1. 「この章の問い」と「到達目標」を読んで、学習の焦点を定める。
2. 教科書の該当章を読み、図を自分の手で描く。
3. 本参考書の「詳細解説」で論理を整理する。
4. 「典型例」または「章末問題」を、答えを隠して解く。
5. 「章末問題」を解き、解答で誤りの原因まで確認する。
6. 翌日、1週間後、1か月後に重要式と間違えた問題だけ復習する。

### 前提となる数学

本書の主要部分は、一次方程式、関数、グラフ、傾きが理解できれば読める。微分を使う箇所では、次の意味を押さえればよい。

- $f'(x)$：$x$をわずかに増やしたときの$f(x)$の変化率
- 偏微分 $\partial f/\partial x$：ほかの変数を固定して$x$だけを変えたときの変化率
- 最大化の一階条件：内点解では通常、限界便益と限界費用が一致する
- 二階条件：一変数の滑らかな内点最大では、通常、目的関数の二階微分が負になる

| 記号 | 意味 |
|---|---|
| $x_1,x_2$ | 財1、財2の消費量 |
| $p_1,p_2$ | 財1、財2の価格 |
| $m$ | 所得または利用可能な貨幣額 |
| $u(x_1,x_2)$ | 効用関数 |
| $MU_i$ | 財$i$の限界効用 |
| $MRS_{12}$ | 財2で測った財1の限界代替率 |
| $y$ | 企業の産出量 |
| $w_1,w_2$ | 生産要素の価格 |
| $c(y)$ | 産出量$y$を生産する費用 |
| $MC,AC,AVC$ | 限界費用、平均費用、平均可変費用 |
| $\pi$ | 利潤 |
| $D(p),S(p)$ | 市場需要、市場供給 |
| $\varepsilon$ | 弾力性 |
