# 付録B 重要公式集

## 消費者理論

| 論点 | 公式 | 読み方 |
|---|---|---|
| 予算制約 | $p_1x_1+p_2x_2\le m$ | 支出は所得以下 |
| 予算線の傾き | $-p_1/p_2$ | 財1の機会費用 |
| 限界代替率 | $MRS_{12}=MU_1/MU_2$ | 財1への主観的交換比率 |
| 内点最適 | $MRS_{12}=p_1/p_2$ | 主観比率と市場比率の一致 |
| コブ＝ダグラス需要 | $x_1=\frac{a}{a+b}\frac m{p_1}$ | 支出割合が一定 |
| スルツキー方程式 | $\frac{\partial x_i}{\partial p_j}=\frac{\partial h_i}{\partial p_j}-x_j\frac{\partial x_i}{\partial m}$ | 価格効果＝代替効果＋所得効果 |
| 価格弾力性 | $\varepsilon=(dx/dp)(p/x)$ | 価格1%変化への数量変化率 |
| 異時点予算 | $c_1+c_2/(1+r)=m_1+m_2/(1+r)$ | 現在価値で収支を揃える |
| 期待効用 | $EU=\sum_s\pi_su(c_s)$ | 状態別効用の確率加重平均 |

## 生産者理論

| 論点 | 公式 | 読み方 |
|---|---|---|
| 限界生産物 | $MP_i=\partial f/\partial x_i$ | 投入1単位の追加産出 |
| 技術的代替率 | $TRS_{12}=MP_1/MP_2$ | 投入間の技術的交換比率 |
| 費用最小化 | $TRS_{12}=w_1/w_2$ | 技術比率と要素価格比の一致 |
| 利潤 | $\pi=py-C(y)$ | 収入−機会費用を含む総費用 |
| 競争企業の産出 | $p=MC(y)$ | 価格＝追加生産費用 |
| 操業停止 | $p\ge\min AVC$ | 短期に可変費を回収できるか |
| 退出条件 | $p\ge\min AC$ | 長期に全費用を回収できるか |
| 生産者余剰 | $PS=py-VC(y)=\pi+F$ | 固定費控除前の余剰 |

## 市場構造と厚生

| 論点 | 公式 | 読み方 |
|---|---|---|
| 市場均衡 | $D(p)=S(p)$ | 希望購入量＝希望販売量 |
| 単位税 | $p_b-p_s=t$ | 買い手価格と売り手価格のくさび |
| 線形税の死荷重 | $DWL=\frac12t\Delta q$ | 失われた取引余剰 |
| 独占の限界収入 | $MR=p(q)+qp'(q)$ | 追加販売の純収入 |
| ラーナー指数 | $(p-MC)/p=1/|\varepsilon|$ | 非弾力的ほど高いマークアップ |
| クールノー複占 | $q_i=(a-c)/(3b)$ | 線形需要・同一限界費用の対称解 |
| 交換効率 | $MRS_A=MRS_B$ | 交換利益が残らない |
| 生産込み効率 | $MRS=MRT$ | 消費評価と生産機会費用の一致 |
| 外部性 | $SMC=PMC+MD$ | 社会費用＝私的費用＋外部損害 |
| 公共財 | $\sum_iMRS_i=MC$ | 限界評価を縦に合計 |
