# 第17章 暴走を防ぐ「錨」の役割

## 17.1 錨とは何か

現実の組織は複数の力を含むが、何でも同じ強さで混ぜればよいわけではない。組織の中心的仕事と歴史に根差す支配的な形態は、全体の一貫性を保つ「錨」になる。

たとえば病院では、診療の熟達が錨になりうる。その上に、感染対策や請求の効率、手術チームの協働、緊急時の統合を載せる。効率が診療判断そのものを支配すると、専門サービスの本質が損なわれる。一方、熟達だけで安全手順や経営規律を拒めば、組織は持続しない。

## 17.2 「エクセレント」の落とし穴

強みは、文脈を失って過剰になると弱みへ反転する。

| 強み | 過剰な状態 | 結果 |
|---|---|---|
| 強いリーダーシップ | すべての判断を奪う | 依存、異論消失、継承不能 |
| 卓越した効率 | 余白を完全に削る | 変化不能、事故の連鎖 |
| 高度な専門性 | 専門家が外部評価を拒む | 閉鎖、顧客不在 |
| 濃密な協働 | すべてを共同決定する | 調整疲れ、責任消失 |
| 強い事業自律 | 共通利益を無視する | 重複、内部競争 |
| 強い文化 | 異質性を排除する | 集団思考、倫理的盲点 |
| 活発な政治 | 対立が自己目的化する | 内耗、崩壊 |

組織の問題は、弱みが足りないことより、強みが暴走していることから生じる場合がある。「もっと強化する」前に、すでに過剰でないかを確認する。

## 17.3 汚染と封じ込め

ある形態の論理が、別の論理を必要とする領域に無差別に入り込むと「汚染」が起きる。

- 研究開発を短期ROIだけで評価する。
- 医療判断を処理時間だけで統制する。
- 給与計算を毎回自由な相互調整で行う。
- 危機時にも全員合意を要求する。
- 共同体への献身を理由に法令手続を省く。

封じ込めとは、異なる論理を排除することではない。適用領域と境界を定めることである。安定運用にはプログラム型、探索にはプロジェクト型を置き、両者を資源配分、技術移管、学習レビューで接続する。

## 17.4 錨を見つける質問

- 組織が存在する最も重要な理由は何か。
- 失うと別の組織になってしまう能力は何か。
- 顧客・利用者が最も信頼しているものは何か。
- 危機時に最後まで守るものは何か。
- 過去の成功を生んだ力と、次の環境で必要な力は同じか。

錨は永久不変ではない。環境や技術が変われば、錨を打ち直す必要がある。ただし、流行の組織手法に合わせて毎年変えるものでもない。
