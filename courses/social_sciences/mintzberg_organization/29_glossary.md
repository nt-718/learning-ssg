# 用語集

## 用語一覧

| 用語 | 意味 |
|---|---|
| アドホクラシー | 固定的官僚制に対し、課題ごとに専門家が組み替わる柔軟な形。現行版のプロジェクト型に近い |
| アナリスト | 他者の仕事を計画・標準化・測定する人 |
| アート | 直観、想像力、ビジョンを用いる知の側面 |
| 外的連合 | 組織外から影響する株主、規制者、顧客、労組などの集合 |
| 外部インフルエンサー | 組織外から資源、規制、評判などで影響する主体 |
| 規範の標準化 | 共有価値・信念をそろえて行動を調整すること |
| 業務の標準化 | 作業手順や工程を事前に定めること |
| クラフト | 経験と実践から形成される熟練・暗黙知 |
| 計画的戦略 | 意図された方向のうち実現した部分 |
| 結果の標準化 | 達成すべき成果や指標を定め、方法はある程度委ねること。本書では成果の標準化 |
| コミュニティシップ | 一人の英雄的リーダーでなく、共同体として組織を担う発想 |
| コンティンジェンシー | 有効な構造は環境・技術・規模などの条件で異なるという考え |
| コンフィギュレーション | 複数の設計要素が整合して一つのまとまりを成す形態 |
| サイエンス | 分析、体系、証拠、測定を用いる知の側面 |
| サポートスタッフ | 基本業務を間接的に支援する人・部署 |
| 事業部型 | 市場別の準自律単位を成果で統制する形態 |
| 水平的分権 | 正式な管理職以外の専門家・現場などへ実質権力を移すこと |
| 垂直的分権 | 正式権限を階層の下位へ移すこと |
| スキルの標準化 | 教育、資格、訓練によって担い手の能力をそろえること |
| 戦略頂点 | 組織全体に責任を負う最高位層。古典版のstrategic apex |
| 相互の調整 | 当事者同士の非公式・直接的コミュニケーションによる調整 |
| 創発戦略 | 当初意図されなかった行動の積み重ねから形成される戦略 |
| 直接的な監督 | 一人が他者へ指示し、仕事を統合すること |
| テクノストラクチャー | 分析・計画・標準化によって他者の仕事へ影響する部分 |
| パーソナル型 | 中心人物が直接監督で全体を統合する形態 |
| ハブ | 中心へ複数の活動が接続する関係形 |
| ハイブリッド | 複数の組織形態・力を組み合わせる構造 |
| プログラム型 | 標準化された工程と階層により効率を追求する形態 |
| プロジェクト型 | 専門家が相互調整し、革新・個別課題を扱う形態 |
| プロフェッショナル型 | 訓練された専門家がスキル標準化で自律的に働く形態 |
| 分離 | 組織単位を切り分け、自律性を与える力 |
| マトリクス | 複数のグループ化基準や権限線を同時に置く構造 |
| ミドルライン | 戦略頂点とオペレーティング・コアをつなぐ管理職層 |
| 未実現戦略 | 意図されたが、実際には実現しなかった戦略 |
| ライン | 基本的な製品・サービスへ直接関わる仕事またはその管理 |
| 連携装置 | 部門間の相互調整を促す役割、会議、チーム、マトリクスなど |
| オペレーティング・コア | 基本的な製品・サービスを生み出す現場部分 |
| オペレーター | 基本的な現場業務を実行する人 |
| 政治アリーナ | 複数勢力の対立が組織全体を支配する形態 |
| 錨 | 組織の一貫性を保つ中心的形態・能力・力 |
| 汚染 | ある形態の論理が、別の論理を必要とする領域へ不適切に侵入すること |
| 封じ込め | 異なる論理の適用領域と境界を定め、破壊的侵入を防ぐこと |
| 選択的分権 | 課題や決定の種類に応じて、異なる場所へ権力を置くこと |
| 並行的分権 | ある単位に関連する複数の意思決定権をまとめて委ねること |
| 形式化 | 行動を規則、手順、職務記述などで規定する度合い |
| 教化 | 組織の価値観・規範を社会化によって身につけさせること |
| ウェブ | 多方向の関係で相互調整する形 |
| セット | 自律的な専門家・単位が並列に存在する形 |
| チェーン | 活動が順番に直列で流れる形 |
| 統合 | 活動を一つの方向・意思へまとめる力 |
| 効率 | 投入当たり成果と再現性を高める力 |
| 熟達 | 高度な技能と専門判断を追求する力 |
| 協働 | 異なる知識・人を相互調整で結びつける力 |
